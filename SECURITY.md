# 安全问题 / Security

发现安全问题请不要发公开的 issue，请通过 [私密报告](https://github.com/kuen133/relay-for-claude/security/advisories/new) 告诉我。

Please do not open a public issue for a security problem. [Report it privately](https://github.com/kuen133/relay-for-claude/security/advisories/new) instead.

报告里请不要附上令牌、Cookie 或 `config.json` 的内容。 Never include tokens, cookies or the contents of `config.json`.
