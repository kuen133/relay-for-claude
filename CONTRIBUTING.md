# 参与贡献 / Contributing

欢迎提 issue 和 pull request。 Issues and pull requests are welcome.

- 提交前请运行 `go vet ./...` 和 `go test ./...`。 Run `go vet ./...` and `go test ./...` before you send a change.
- 说明你在哪个系统上测试过。 Say which system you tested on.
- 不要在 issue 或日志里贴出令牌、Cookie 或 `config.json`。 Never post tokens, cookies or `config.json`.
